# tugaspersonal_2b
Soal Case 2 - sistem kasir toko yang menggunakan struktur data Stack dan Queue 
Spesifikasi Program
1.	Antrian Pelanggan (Queue Mode)
  o	Input: nomorAntrian, namaPelanggan, totalBelanja.
  o	Minimal 5 pelanggan dalam antrian.
  o	Jika pelanggan selesai dilayani, lakukan dequeue.
2.	Riwayat Transaksi (Stack Mode)
  o	Setiap pelanggan yang selesai dilayani, data transaksinya disimpan ke stack.
  o	Stack menampilkan transaksi terbaru di atas (LIFO).
3.	Menu Program
  o	Tambah antrian pelanggan (enqueue).
  o	Layani pelanggan (dequeue + push ke stack).
  o	Tampilkan antrian saat ini.
  o	Lihat riwayat transaksi dari terbaru ke lama.
  o	Keluar program.
